# Verbo

Jogo de adivinhação de palavras de 5 letras, feito com React + Vite e Tailwind 4.

## Modo de jogar

O jogador tem 6 chances para acertar a palavra secreta de 5 letra, caso a casa da letra fique verde, significa que a letra está no lugar correto. Caso fique amarela, a letra existe na palavra, porém está na posição errada. Caso a cor escureça, a letra não está na palavra.

## Objetivo do projeto

Aprimorar conhecimentos em React e Tailwind, desevolvendo uma aplicação interativa com componentes reutilizáveis, eventos manipulaveis, estados gerenciados e estilização mobile-first com a versão 4 do Tailwind CSS. Criar interface simples, mas também interativa e responsiva.
